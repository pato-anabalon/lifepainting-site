## Animation
Implemented: preloader + hero. Modules in `src/lib/motion/`: `register.ts` (plugins + `LIFE_MOTION_OK`), `preloader.ts` (PRELOADER), `once.ts` (ONCE), `brushWipe.ts` (preloader brush), `smooth.ts` (easing helpers for the collage loop). `scrub.ts` (GSAP scrub layers for the old SVG backdrop) was removed on 2026-11-01, unused; the only scrub left is the collage's scroll lift inside `LifeHeroCollage`. Hover stays in CSS (Button).
- **Preloader** `LifePaintingPreloader`: monogram fade-in + shimmer (1.6 s), then a sprite brush wipe (`src/lib/motion/brushWipe.ts`, after the GSAP stepped-sprite technique in Unseen Studio's CodePen "LZLLEM"; the canvas bristle version was rejected by the owner): rows of a real brush stroke (sprite `public/brush/brush-stroke-cream.webp`, 22 frames of 1000×205, recoloured to `--lp-cream`) overlap by 22 % and paint top to bottom, each one stepped left to right with `steps(21)`; 1.5 s for all rows (15 % overlap between rows), then the overlay fades in 0.3 s and the preloader is marked done, so the hero (collage + logo, H1, intro, buttons) appears on cream. Strokes run along the long side: across on landscape, down the screen on portrait (the row stage is transposed); the row count (2–6) is the one that keeps the stroke closest to its own proportions (1440×900 → 4 rows, 390×844 → 3, 768×1024 → 5). The sprite starts loading when the preloader mounts and the brush waits for it to decode; if it fails the preloader just ends. ≈3.4 s total. **Fail-safes (2026-10-31, after an intermittent "stuck on the monogram" report that could not be reproduced in 34 headless loads):** the overlay only leaves when the app's JS finishes it, so (1) the boot script starts an 8 s watchdog that marks the preloader done and fires the done event if the JS never runs or never mounts the preloader (chunk/hydration error); the preloader clears it on mount; (2) from mount the preloader has its own hard deadline (≈7.4 s); (3) the sprite wait is capped at 2.5 s, after which the overlay just fades out without the brush. Tested by blocking the sprite (overlay fades at ≈2.5–2.8 s) and blocking the JS chunks (the static green + monogram screen, released at 8 s). **Asset licence:** the sprite comes from that public CodePen (Unseen Studio); the owner confirmed it is under a free licence (2026-11-01). A boot script in `<body>` sets `html[data-lp-preloader]` = `pending|skip` before paint; CSS hides the overlay unless `pending` (no JS → hidden; reduced motion or already seen this session → `skip`). `done` after finishing. Page scroll is locked only while `pending`.
- **Hero** (`HeroSection`, server) = `LifeHeroCollage` (client: ONCE intro after the preloader, 3D mouse parallax, SCRUB lift on scroll) + `LifeHeroReveal` (ONCE stagger of logo, H1, intro, buttons). Both wait for the preloader. Nothing loops. Reduced motion → static collage, visible content. Details under "Hero: photo collage".
- Motifs are generated SVG in palette colours, inspired by the guidelines' mid-century graphics (pennants/starburst/sunburst). Swap for exact brand artwork if the client provides vector files.
Original plan:
Four separate modules: `scrub`, `once`, `hover`, `preloader`. `useGSAP` with cleanup, scoped to the section, transform/opacity only,
`prefers-reduced-motion` gives a static alternative. Preloader once per session and skipped under reduced motion.
